🖥️ Runtime Protection

The 61 checks above scan your code before it ships. Loophole Server Guard is the other half — a runtime tool that watches the server while it runs, and rings the alarm the moment someone comes probing.

🛡️

Loophole Server Guard — live server protection

Server Guard tails your web (Apache/Nginx) and SSH/auth logs in real time and scores every IP that touches your server. Probes for /.env and /wp-admin, SQL injection, XSS, path traversal, scanner tools (sqlmap, nikto, nuclei) and SSH brute force all add to an attacker's score. Cross the warn line and you get an alert — terminal, email, Telegram or webhook — with the attacker's IP. Cross the ban line and the IP is banned at the firewall (iptables, nft or ufw) with an expiry. Your own IPs sit on a whitelist that can never be banned, and every firewall action runs in dry-run — logging the exact command it would run — until you switch dry-run off. Decoy honeypot ports (a fake SSH server, fake WordPress and phpMyAdmin logins, a fake .env) catch anyone poking around, every incident is stored in SQLite, and a local dashboard shows top attackers, active bans and recent incidents.

# see it work in 10 seconds — built-in web + SSH attack demo, dry-run ban
python3 sitealarm.py demo

# one-shot analysis of an existing log
python3 sitealarm.py scan-log /var/log/nginx/access.log

# run Loophole's code checks against the server's code, right now
python3 sitealarm.py codescan

# daemon — watch logs + honeypot + scheduled code scans
python3 sitealarm.py --config sitealarm.json run

# live dashboard — top attackers, active bans, incidents
python3 sitealarm.py dashboard

And because it's Loophole: Server Guard also runs Loophole's own 61 code checks against the server's code on a schedule. New critical or high findings raise the same alarm and the same alerts — so code holes and live attacks show up in one dashboard. Pure Python 3 standard library, zero dependencies — same rule as the scanner.
